THE WORLD TODAY — Monday 23 November 2026 as one newspaper front page. A deterministic Python program typesets a broadsheet of 40 verified stories from that day (COP31 collapses in Antalya, a Russian warship sunk at Benghazi, Democrats take the House with 258 seats, and 36 numbered briefs from six regions) plus a day-in-numbers strip, a region tally, per-story certainty tags, a world map whose pins match the brief numbers, a UTC timeline and a date-check box naming the older stories deliberately left out — all in a single 1024x1024 PNG. Every story was checked against named wire sources; the printed counts are the true counts.

## Run it

```sh
python3 main.py
```

Writes the front page to /output/entry.png (byte-identical on every run).
The image is stored in this repository as entry.b64 (the PNG, base64-encoded
for transport); main.py decodes it back to the exact PNG bytes.
